Проект самописных скриптов на основе Empyrion Scripting by Astic's

Описание скриптов:

   colors
        Описывает управление светильниками и типами освещения.

   constructonOnIfResources
        Пример включения принтера в зависимости от наличия ресурсов

   fastDeconstruct
        Скрипт разбора кораблей на блоки с максимальной скоростью. Оставляет контейнеры (Не дописан, некоторые контейнеры разбирает)
   
   getItemId
        Получение id предметов из контейнера Test
    
   itemMoveFromEnemy
        Скачивает ресурсы из другой структуры. 
        Требования:
            Контейнеры должны быть переименованы.
            Структура должна быть той же фракции

   moveItem
        Несколько примеров перемещения предметов по id и количеству
        
   printMoney
        Печатает деньги

   searchItem
        Ищет предметы из контейнера Test в ПЕРЕИМЕНОВАННЫХ контролёрах по всему кораблю и складывает в "Найдено"
    
   shieldDisplay
        Отображение количества щитов, отображение урона и включение устройств с названием Tt1, Tt2, Tt3 в зависимости от урона получаемого по щиту в интервал времени (3 уровня угрозы)
    
   trash
        Просто мусорка
